# End-to-End Lens Modeling of HST and JWST data with dolphin

This repository stores the modeling and analysis notebooks for an end-to-end cosmological analysis with `dolphin` (paper in prep). This repository is organized as follows:

1) `simulation/`: Stores the model settings, input data, and outputs for a simulated quadruply imaged quasar in the JWST F115W band.
2) `starred_models/`: Stores the model settings, input data, and outputs for the HST double and JWST quad whose PSF was created via the `STARRED` methodology.
3) `psfr_models/`: Stores the model settings, input data, and outputs for the HST double and JWST quad whose PSF was created via the `PSFr` methodology.
4) `preprocessing/`: Stores notebooks for image cutout and PSF creation for J1620+1203 and WFI2033. *Note: the full calibrated image files will be uploaded to Zenodo once the paper is submitted, as the files are too large to store on GitHub.*
